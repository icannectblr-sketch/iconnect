# Home page typography override

- **Display / headings / wordmark:** Outfit, weights 600–800. Use for the hero statement, section headings, product names, and brand mark.
- **Body / UI copy:** Work Sans, weights 400–700. Use for descriptions, forms, navigation, and service copy.
- **Operational labels / prices:** IBM Plex Mono, weights 400–600. Keep the compact technical feel for badges, prices, and branch metadata.
- **Intent:** Outfit gives the phone-shop experience a more geometric, contemporary silhouette; Work Sans keeps long descriptions and forms calm and readable.

GoDaddy Node.js deployment notes

1. Upload and extract this ZIP into your Node.js application folder (the folder containing package.json).
2. Select Node.js 22 or the compatible version offered by your GoDaddy plan.
3. Install dependencies using the hosting panel's install button, or run: npm install --include=dev
4. Set the application startup file/command to: npm start
5. Add these environment variables in the hosting panel. Do not put secrets in the ZIP:
   NODE_ENV=production
   DATABASE_URL=mysql://DB_USER:DB_PASSWORD@DB_HOST:3306/DB_NAME
   MANUS_PROJECT_ID=your-project-id
   MANUS_JWT_SECRET=use-a-long-random-secret
   MANUS_OAUTH_API_URL=your-Manus-OAuth-API-URL
   MANUS_API_URL=your-Manus-API-URL
   MANUS_API_KEY=your-server-side-Manus-API-key
   PORT is normally supplied by the hosting panel; do not hard-code it if the panel supplies one.
6. Run database migrations from the app folder: npx drizzle-kit migrate
7. Open /signup on your site and create the admin account. In cPanel phpMyAdmin, choose the app database, open SQL, and run:
   UPDATE users SET role = 'admin' WHERE email = 'Nishanthnimba@gmail.com';
8. Restart the Node.js app in the hosting panel.

This ZIP contains the production build and migrations. It intentionally excludes node_modules and any .env file. Product image uploads and AI descriptions require valid Manus service API settings.
